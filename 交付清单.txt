二、怎么用（主用法 = PDMS 内菜单；安装务必在 PDMS 停机时）
--------------------------------------------------------------------------
  【第一步：装原生插件（R3 主路线，PDMS 停机时）】
        cd /d <本目录>\PDMS原生插件\deploy
        python deploy_pkpmjwd.py               <- dry-run：打印"将要改变的全部对象"，不落盘
        python deploy_pkpmjwd.py --execute     <- 确认清单无误后真执行（PDMS 必须已停机！）
    改动 5 步（只加不删、幂等、可回滚）：备份两个 XML（.pkpmjwd-bak）-> DesignAddins.xml
    追加 <string>PKPMJWD</string> -> DesignCustomization.xml 追加 <CustomizationFile/>（最易漏）
    -> 复制 dist\PKPMJWD.dll、dist\pkpmjwd.uic 到 <PDMS根>\ -> 写 PKPMJWD\engine_path.txt 与
    pml\pkpmjwduniquename.pmlfnc。
  【第二步（可选）：装 legacy PML（原生窗体的导出功能需要）】
        powershell -NoProfile -ExecutionPolicy Bypass -File 插件包\install\install.ps1 -DryRun
        powershell -NoProfile -ExecutionPolicy Bypass -File 插件包\install\install.ps1
  【第三步：完全退出并重启 PDMS】-> DESIGN 模块菜单栏出现「PKPM JWD」->「PKPM JWD 导入导出」
    打开原生窗体（主用法）：一窗三向——转换（jwd2pdt/pdt2jwd 等）、建 PDMS 模型（jwd2pdms/
    pdt2pdms，宏自动 $M 执行、宏内重名自动加 re 后缀）、截面库（jwd2db/pdt2db 生成目录/规格宏）、
    导出（pdms2jwd/pdms2pdt，经 PML !!pkpmjwdexport 取 PDMSDUMP 文本）；执行完看摘要与 report.json。
  【备用】外置命令行：python engine\cli.py --help（12 子命令）；免 Python：
    engine\dist\pkpmjwd_engine.exe；桌面图形界面：python engine\gui.py（五页签）。
  【卸载】原生插件：python undeploy_pkpmjwd.py（先 dry-run；XML 从 .pkpmjwd-bak 逐字节复原、
    4 个安装文件移入 _uninstalled_<时间>\，不删除）；legacy：install\uninstall.ps1（先 -DryRun）。
  注：截面匹配文件用你自己的《PKPM转PDMS截面匹配文件.txt》（按交付纪律不随包分发）。
