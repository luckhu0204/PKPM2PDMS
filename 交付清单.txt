二、怎么用（主用法 = PDMS 内菜单；安装务必在 PDMS 停机时）
--------------------------------------------------------------------------
  【第一步：装原生插件（主路线，PDMS 停机时）】
        cd /d <本目录>\PDMS原生插件\deploy
        python deploy_pkpm2pdms.py               <- dry-run：打印"将要改变的全部对象"，不落盘
        python deploy_pkpm2pdms.py --execute     <- 确认清单无误后真执行（PDMS 必须已停机！）
    改动 5 步（只加不删、幂等、可回滚）：备份两个 XML（.pkpm2pdms-bak）-> DesignAddins.xml
    追加 <string>PKPM2PDMS</string> -> DesignCustomization.xml 追加 <CustomizationFile/>
    -> 复制 dist\PKPM2PDMS.dll、dist\pkpm2pdms.uic 到 <PDMS根>\ -> 写 PKPM2PDMS\engine_path.txt
    与 pml\pkpm2pdmsuniquename.pmlfnc。
  【第二步（可选）：装 legacy PML（原生窗体的导出功能需要）】
        powershell -NoProfile -ExecutionPolicy Bypass -File 插件包\install\install.ps1 -DryRun
        powershell -NoProfile -ExecutionPolicy Bypass -File 插件包\install\install.ps1
  【第三步：完全退出并重启 PDMS】-> DESIGN 模块菜单栏出现「PKPM2PDMS」（原生）与
    「PKPM2PDMS PML」（legacy）两个菜单。
  【备用入口】命令行：PKPM2PDMS_引擎_v2.1.0.exe --cli --help（12 子命令）；源码：
    插件包\engine\cli.py；图形界面：PKPM2PDMS_引擎_v2.1.0.exe（无参数）。
  【卸载】原生插件：python undeploy_pkpm2pdms.py（先 dry-run；XML 从 .pkpm2pdms-bak
    逐字节复原、安装文件移入 _uninstalled_<时间>\，不删除）；legacy：install\uninstall.ps1（先 -DryRun）。
  注：截面匹配文件用你自己的《PKPM转PDMS截面匹配文件.txt》（按交付纪律不随包分发）。

六、v2.1.0 的兼容性代价与迁移（必读）
--------------------------------------------------------------------------
  1. PDMSDUMP 文本首行 magic 从 #PKPM-JWD-PDMSDUMP 改为 #PKPM2PDMS-PDMSDUMP（其后
     格式版本 1.0 不变）。pdms2jwd / pdms2pdt 对首行硬校验：**v2.0 生成的旧 dump 文本
     会被 v2.1.0 引擎拒绝**。迁移：用旧引擎，或把旧文本首行的 #PKPM-JWD-PDMSDUMP 手工
     替换为 #PKPM2PDMS-PDMSDUMP（其余行不动）。本版不加自动兼容分支。
  2. 备份后缀从 .pkpmjwd-bak 改为 .pkpm2pdms-bak，PMLLIB 子目录从 pkpmjwd\ 改为
     pkpm2pdms\：**v2.0 时代的旧安装与旧备份不被新版识别**。请先用 v2.0 的卸载脚本
     卸干净，再装 v2.1.0（不要在代码里为旧后缀加兼容分支）。
