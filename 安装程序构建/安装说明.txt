================================================================
 PKPM2PDMS导入导出 v2.1.0 —— 安装程序（exe 版）
================================================================

这个文件夹里有两个 exe，都是免安装、免 Python 环境、双击就能跑：

  PKPM2PDMS_安装程序_v2.1.0.exe
      把插件装进 PDMS（或卸载）。对应包内 install/install.ps1 与 uninstall.ps1，
      但不需要命令行、不受 PowerShell 执行策略限制。

  PKPM2PDMS_引擎_v2.1.0.exe
      转换引擎。双击 = 图形界面；带 --cli = 命令行。
      对应包内 engine/cli.py 与 engine/gui.py（不需要本机装 Python）。
      内嵌了随包截面转化表 section_table.csv（v1 的旧引擎没有，见下面第五节）。


----------------------------------------------------------------
一、安装到 PDMS（三步）
----------------------------------------------------------------

1) 双击 PKPM2PDMS_安装程序_v2.1.0.exe

2) 确认「PDMS 安装根目录」（程序会自动探测，一般是
   D:\AVEVA\Plant\PDMS12.1.SP4，判断依据是目录里有 design.uic）

3) 先选「仅预览（推荐先做一次）」，点「执行」——它会把将要做的每一处改动
   完整打印出来，但**不写任何文件**。确认没问题后，把选项改成「安装」再执行一次。

安装会做两件事：
   · 把 4 个 PML 文件复制到 <PDMS根>\PMLLIB\pkpm2pdms\
     （pkpm2pdms.pmlfrm / pkpm2pdmsexport.pmlfnc / pkpm2pdmsdbexport.pmlfnc /
       pkpm2pdmsrun.mac —— 与 install.ps1 的 $required 清单逐字相同）
   · 先备份、再往 <PDMS根>\design.uic 追加一个「PKPM2PDMS PML」菜单项
     （备份名：design.uic.bak_pkpm2pdms_<日期时间>）

然后把 PDMS 完全退出再重启。进入 DESIGN 模块后，菜单栏会出现「PKPM2PDMS PML」
（原生 .NET 插件另有一个菜单项叫「PKPM2PDMS」，两个是两条不同安装路线）；
也可以在命令行执行：
   $m "%PMLLIB%/pkpm2pdms/pkpm2pdmsrun.mac"

卸载：同一程序里选「卸载」再执行。它只移除本包自己的三处菜单条目，
design.uic 会恢复到与安装前**逐字节相同**；包目录是整体「移动」到
PMLLIB\_removed_pkpm2pdms_<时间> 而**不删除**，确认无误后可自行清理。

还原到某次安装前的状态：勾选「卸载时改用安装前备份整份恢复 design.uic」。


----------------------------------------------------------------
二、用引擎做转换
----------------------------------------------------------------

双击 PKPM2PDMS_引擎_v2.1.0.exe，界面有五个页签：
   ① .jwd → PDMS 宏        （JWD 导入 PDMS 用这个）
   ② PDMS 文本 → .jwd      （PDMS 导出成 JWD 用这个）
   ③ .pdt → model.json     （读取 PKPM 的 .pdt 中间模型）
   ④ 数据库转化            （目录宏 / 规格宏 / 截面转化表）
   ⑤ 格式互转

也可以命令行（便于批处理）：
   PKPM2PDMS_引擎_v2.1.0.exe --cli --help
   PKPM2PDMS_引擎_v2.1.0.exe --cli jwd2pdms "工程.jwd" --out "模型.mac" --secmap "PKPM转PDMS截面匹配文件.txt" --project 工程名
   PKPM2PDMS_引擎_v2.1.0.exe --cli pdms2jwd "从PDMS导出的文本.txt" --out "结果.jwd"

构建阶段会把这个 exe 另拷一份到 插件包\engine\dist\pkpm2pdms_engine.exe
（.NET 原生窗体的 engine_path.txt 指向的就是这个名字），两者是同一个 exe。


----------------------------------------------------------------
三、安全性说明（这个程序不会做什么）
----------------------------------------------------------------

· 不删除任何文件。卸载默认是「整目录移动」；只有显式加 --purge 才逐条删除，
  且会先把每个要删的完整路径打印出来。
· 不改 DesignAddins.xml（本包是纯 PML，没有 .NET add-in 可登记）。
· 不重排、不改写 design.uic 里既有的条目（TGTEXT / PDCOPILOT 等原样保留）。
· 不改 PMLLIB\pml.index，不动 P-TRANS 目录，不动 .jwd / .pdt / 截面匹配文件等原件。
· 安装前若检测到 PDMS 正在运行，会拒绝安装（PDMS 在跑时覆盖 PML 会读不到新代码）。
· 不写 G 盘样本区：构建脚本的输入输出都只在本工作树内。


----------------------------------------------------------------
四、验证依据（怎么知道它是可信的）
----------------------------------------------------------------

· 安装程序的核心逻辑与原 install.ps1 / uninstall.ps1 做过**字节级等价验证**：
  同一份 design.uic，两边各自真装一遍，产物逐字节相同。
· 沙箱自测覆盖：预览不落盘、安装、重复安装幂等、卸载后设计文件字节级还原、
  重复卸载幂等、包目录移动而非删除、异常输入（缺 design.uic / 非法 XML /
  非 UTF-8 / 目录不存在）的退出码。
· 引擎 exe 的转换产物与源码引擎的产物逐行相同（忽略自动时间戳行）。
· 图标：安装程序与引擎 exe 都带 pkpm2pdms.ico（深蓝底 + 白门式刚架 + 白右箭头），
  由 图标\make_icon.py 可复现生成（16/24/32/48/64/128/256 七个尺寸）。

【部署状态】本包**未在真实 PDMS 里装过**：实机测试由工作流（工作树 计划\TEST_PLAN.md）
统一执行，本安装说明只负责讲清步骤。首次安装请务必先用「仅预览」看一遍，再执行安装。


----------------------------------------------------------------
五、退出码（命令行模式下）
----------------------------------------------------------------

   0 = 成功
   2 = 参数或路径不对（PDMS 根目录 / design.uic / 源包缺失）
   3 = 检查未通过（design.uic 非合法 UTF-8 或 XML、源包编码不符）
   4 = PDMS 正在运行
   5 = 写盘失败或写后校验失败（已自动回滚，详见输出）


----------------------------------------------------------------
六、本包与主包的关系
----------------------------------------------------------------

本文件夹只是「安装程序的 exe 版 + 打包脚本」。插件本体（引擎源码、PML、安装脚本、
验收测试、格式规范、交付报告）在上一级：

   插件包\          引擎（engine\）、PDMS 侧 PML（pdms\，GBK 无 BOM + CRLF）、
                    legacy 安装脚本（install\）、文档（docs\）、契约（spec\）
   PDMS原生插件\     R3 的 .NET 原生插件源码与部署脚本
   图标\            图标生成脚本与产物
   安装程序\        本脚本产出的两个 exe（由构建阶段执行）

exe 只是把同一份 PML 与引擎打进去、套了个图形界面，逻辑与源码版一致；
它内嵌的资源直接取自 插件包\pdms、插件包\docs、插件包\engine（唯一真源）。
