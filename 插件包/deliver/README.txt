deliver/ —— 最终交付物归集
==========================

用途
----
把"给用户的那一份"集中在这里，便于整体拷贝到 PDMS 侧或存档：

  deliver/
    PKPM-JWD导入导出_v1.0/          整个可运行包（engine/ + pdms/ + install/ + docs/）
    交付清单.md / 交付清单.txt      逐条列出：新增了哪些文件、安装会改哪些文件、如何回滚
    校验和.txt                    对交付文件逐一计算哈希（SHA256），供完整性核对
    实机验证记录.md               实机跑过的证据（命令、输出、结论）；**没跑就写"未实机"**

纪律
----
  1. 只归集本包自己生成的文件；**不得**把用户原件（.jwd/.pdt/匹配文件/目录宏）复制进来
     作为"交付物"——它们是用户的，不随本包分发。
  2. 交付目录里的内容必须与源目录**逐字节一致**（用哈希核对），不得手改后再交付。
  3. 任何"未实机验证"的结论必须在交付清单里显式标注，不得省略。
  4. 不删除历史交付目录；新版本用带版本号的目录名（`..._v1.1`）。
