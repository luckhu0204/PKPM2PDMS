spec/out/ —— 样例、夹具与留档
=============================

用途
----
  1. **联调夹具**：CONTRACT.md §c.4 的 PDMSDUMP 最小示例（GBK 无 BOM + CRLF），
     供 engine/pdms_dump.py 与 test/test_dump.py 双向使用。
  2. **留档**：每次实机验证/回归产生的关键产物（宏摘录、报告摘要、比对表）留一份在这里，
     文件名带日期与来源，例如：
        dump_min_1.0.txt              契约 §c.4 夹具
        out_JLCJ2_20260923.report.json 某次转换的报告
        mac_JLCJ2_20260923.head.txt    宏的前 N 行摘录（实机验证前的人工核对件）
  3. **不存放**：用户原件副本、PDMS 安装内文件的副本、任何二进制。

纪律
----
  * 本目录只由**追加**方式增长；不删除、不覆盖他人留档（同名时加日期/序号后缀）。
  * 编码：PDMSDUMP 类文本 GBK + CRLF；json/md UTF-8 无 BOM。
  * 留档文件必须能在文件头说明：来源命令、日期、是否实机、结论。
