  交付清单.md         改了哪些文件、装了什么、如何回滚

纪律
----
  * 编码 UTF-8 无 BOM（与 Python 源码一致），便于 git diff 与跨包读写。
  * 证据分级必须随文给出：**文件/行号级直证**、**样本数据自检**、**未实机** 三者不得混写。
    本包一切 PDMS 语法结论都来自本机安装内 PML 源码的静态阅读，
    **未在 PDMS 实机运行过**，文档不得写成"已验证可用"。
  * 未解项（Kind=3 族别、Kind=2 B/T 交错序、Ecc 正负方向、荷载语义、单条 HDiff2=6650 等）
    必须原样保留在文档里，不得为了让文档"好看"而删掉。
