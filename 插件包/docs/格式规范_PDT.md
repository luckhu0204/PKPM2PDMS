# 格式规范 —— PKPM `.pdt`（交付版，含写出契约）

> 来源：样本 `1_PM.pdt`（9,677 行，GBK/CRLF）的只读解析、现有插件 `P-TRANS\PDMSxCA_Addin*.dll`
> 内格式串的逐字核对、以及本包实现（`engine/pdt_read.py` 读、`engine/pdt_write.py` 写）。
> 执行条款见 `spec/CONTRACT.md` §b.4（读）与 §j（写，R2 新增）。
> **证据分级**：**【事实】** = 有字节/逐行级直证；**【推断】** = 由证据推得、机理未证实（实现可编码但必须留痕）；
> **【未确证】** = 明确未解（禁止猜测，只报出）。**未在 PDMS 实机验证**的地方逐条标注。

## 1. 文件性质与词法

`.pdt` 是 PKPM 与 PDMS 插件（P-TRANS）之间的**文本**交换文件。三层结构：
**节（`$` 行）→ 记录（缩进 4 空格）→ 字段（`KEY= 值`，逗号分隔）**，另有续行（缩进 7/8/11 空格）。

| 规则 | 级别 | 说明 |
|---|---|---|
| 编码 **GBK、CRLF、无 BOM** | 【事实】 | 首行注释 + 30 个中文截面名是仅有的非 ASCII；GBK 解码 31/31 成功 |
| `;` 开头 = 注释；空行忽略；`$` 开头 = 节头 | 【事实】 | 样本 25 个节头 |
| **缩进即语法**：≤4 空格 = 新记录；>4 = 上一记录的续行 | 【事实】 | 全文缩进只有 3/4/7/8/11 五种，反例 0 |
| 续行以 `KEY=` 开头 → 新字段；以**裸值**开头 → 追加到上一物理行的最后一个字段（跨行记忆 `last_key`） | 【事实】 | `EXR`（约 200 列处折断）与 `$RIGID.SLABID`（每 20 个 ID 折行，续行 11 空格）两处实际发生 |
| 每节数据区末尾恰 1 空行；无"记录条数"头行 | 【事实】 | |
| `EXI=`/`EXR=`：首数 = 属性组数 N，其后 N 组 `(属性ID, 值)`；**声明 N 与实际组数完全一致**（全部节 0 处不一致） | 【事实】 | N 可作解析自校验位 |
| 单位：坐标/尺寸 **mm**；`$DEFMATERIAL.ES` **MPa**、`DS` **kN/m³**；荷载 kN/kN·m/kN/m²；**线荷载的 `DS`/`S` 是 m**（与几何 mm 不同——最易踩的单位陷阱） | 【事实/推断-高】 | |

**文件里没有**（【事实】，不要找）：支座/边界条件、端部释放（铰接）、配筋、风/地震工况、质量/周期、基础详图。

## 2. 13 段逐段规范（段序冻结，不得增删）

段序（`$VERSION → $DESIGNPARA → $STORY → $NODECOOR → $NET → $DEFFRAMESECTION →
$DEFWASLABSECTION → $DEFMATERIAL → $SETELEMENT → $SETWALL → $SETSLAB → $RIGID → 荷载组 → $END`）
为【事实】（样本 L1–L9677 逐段实测；写出契约 §j.2-2 同序）。

样本各段记录数：`$STORY` 5 / `$NODECOOR` 617 / `$NET` 1058 / `$DEFFRAMESECTION` 32 /
`$DEFWASLABSECTION` 4 / `$DEFMATERIAL` 5 / `$SETELEMENT` 1046 / `$SETWALL` 4 / `$SETSLAB` 331 /
`$RIGID` 6 / 荷载段见 §4。

### 2.1 `$VERSION`
段体一行裸值 `   4.2.0`（3 空格缩进）【事实】。

### 2.2 `$DESIGNPARA`
50 行 × 20 列 = 1,000 个浮点数，**无字段名**【事实】。20 行全零；第 10/15 行是 0/1 标志行。
**逐项含义【未确证】**（无官方字段表，不做臆测）⇒ PDMS 建模不需要这些参数；
本包写出时**原样透传**或写全 0 占位（`PdtOptions.designpara`，契约 §j.4.3）。

### 2.3 `$STORY`（层）
```
    ID=1, NUB=1
       NO=1, HI=8300, BL=-1300, TL=7000, WID=15200.00, LEN=49400.00, HEI=12000.00
```
`ID` 层号（1 起）、`BL` 层底标高 mm、`TL` 层顶标高 mm（均【事实】）；`HI` = TL−BL【事实】；
`WID/LEN` = 层平面 Y/X 向外包尺寸、`HEI` = 该层最大结构高度（越层柱）【推断-高】。

### 2.4 `$NODECOOR`（节点，每条 2 行）
```
    ID= 3807, X= 1580.00, Y= 15200.00, Z= 11700.00, FLOORID= 2
       EXR= 2 ,10005, 2 ,10012, 2e+06
```
`ID`（末两位恒 07）、`X/Y/Z`（mm）、`FLOORID` ⇒ `$STORY.ID` 均【事实】；
`EXR.10005` = `FLOORID`【事实】；`EXR.10012` = `层号×1e6 + 层内序号`【推断-高】。

### 2.5 `$NET`（线段/构件轴，每条 1 行，无 EXI/EXR）
```
    ID=65908, NODES=53207, NODEE=10207
```
`NODES/NODEE` ⇒ `$NODECOOR.ID`【事实】；端点 0 悬空。1058 = 1046 构件 + 12 条墙环边。

### 2.6 `$DEFFRAMESECTION`（框架截面，每条 5 行）
```
    ID=609, NAME=矩750X750, SHAPE=1
       KIND=1, B1=750, B2=0, H1=750, H2=0, B3=0, H3=0
       T1=0, T2=0, T3=0, T4=0, T5=0, T6=0
       M=6, RI=0.000, RJ=0.000, UA=0.000, NAME1=
       EXI=1, 10011, 609
```
| 字段 | 含义 | 级别 |
|---|---|---|
| `ID`（末两位 09）/ `NAME` | 截面 ID / PKPM 截面名（中文"矩/圆形…"或型钢牌号） | 【事实】 |
| `SHAPE` / `KIND` | 截面形状码（本文件两者恒等【事实】；词表见 §3.2） | 【推断-中】(SHAPE 语义) |
| `B1..B3 / H1..H3` | SHAPE=1：B1×H1 = 矩形宽×高；SHAPE=3：B1 = 直径；SHAPE=39：B1=翼缘宽、H1=高 | 【推断-高】 |
| `T1..T6` | 壁厚系列，**本文件全 0（32/32）** ⇒ **型钢板厚不在此格式里**，只能靠 `NAME/NAME1` 查匹配文件 | 【事实】 |
| `M` | **按 SHAPE 取：1/3 → 6、39 → 5**（材料/子类型码；R2 修订，契约 §0.4-10/§12#17） | 【推断-中】 |
| `RI/RJ/UA` | 全 0；语义未确证 | 【未确证】 |
| `NAME1` | 型钢牌号（`HN400X200` 等有值，其余空） | 【推断-中】 |
| `EXI.10011` | = 自身 ID（自校验） | 【事实】 |

### 2.7 `$DEFWASLABSECTION`（墙/板截面，每条 1 行）
```
    ID=183711, NAME=T600, TYPE=1, T1=600.00, T2=0.00
```
`NAME` = `T<厚度mm>`【事实】；`T1` 厚度 mm【事实】；`ID` 末两位 **11**【事实】；
`TYPE` 恒 1【推断-低】；`T2` 0【未确证】。同名不同 ID 的两行 `T120` ⇒ 材质/用途不同，按 ID 引用。

### 2.8 `$DEFMATERIAL`（材料，每条 1 行）
```
    ID=110, NAME=C30, TYPE=262, ES=3e+04, PR=0.2, EXC=1e-05, DS=26
```
`TYPE`：**261 = 钢、262 = 混凝土**【推断-高】（NAME/ES/DS 交叉验证）；`ES` MPa、`PR` 泊松比、
`EXC` 线膨胀、`DS` kN/m³。**注意材料重名**：样本 `C30` 有 ID 110(DS=26) 与 310(DS=25) 两条，
构件实际引用 310 ⇒ **按 ID 而非按名字取材料**【事实】。

### 2.9 `$SETELEMENT`（构件，1046 条；1045 条 4 行 + 1 条 5 行）
```
    ID=65908, TYPE=2, NETID=65908, SECTID=1509, MATID1=310, MATID2=-9999, ECS1=0.000, …, ANG=0.000
       EXI=3, 10011, 65908, 10013, 30, 10014, 0
       EXR=19, -1004, 0.000, …, 10005, 3.000, 10012, 3000441.000
        (EXR 折行，8 空格续行)
```
| 字段 | 含义 | 级别 |
|---|---|---|
| `ID` == `NETID`（1046/1046） | 构件 = 一条 NET | 【事实】 |
| `TYPE` | **1 = 柱（121 条全竖直）、2 = 梁（925 条全水平）**；本样本无支撑 | 【事实】（几何验证 100%） |
| `SECTID` ⇒ 2.6 / `MATID1` ⇒ 2.8 / `MATID2=-9999` = 无次材料 | | 【事实】 |
| `ECS1..ECE3` | **偏心归属按实测**：121 根**梁**（TYPE=2）ECS1=ECE1=225/250 等非零，**柱全 0**（R2 勘误，`pdt_format.md` §2.9 原文已注明） | 【事实】（分布） |
| `ANG` | 绕构件轴转角，全 0 | 【事实】（样本） |
| `EXI.10013/10014` | 材料等级：混凝土 `30/0`、钢 `0/235` | 【推断-高】 |
| `EXR.-41` = TYPE；`EXR.-68=-40=10005` = 楼层号 | | 【事实】 |
| `EXR.10012` = 层号×1e6+层内序号 | | 【推断-高】 |
| `EXR.-1001..-1004` | 与 `ECS*` 冗余的偏心量，**顺序/符号与记录头不一致**（有反例）⇒ 以记录头为准 | 【事实】（矛盾存在） |
| `EXR.-43 / -42 / -57 / -84 / 10001..10003` 等 | 语义**未确证**（`-43` 已排除长度/面积/周长/体积/自重） | 【未确证】 |

### 2.10 `$SETWALL` / `$SETSLAB`（墙 4 / 板 331，每条 4–5 行）
```
    ID=183805, TYPE=5, SECTID=183711, MATID=310, MATID2=0, HOLEID=-9999, EC=0.0
       NUB=4, NETID= 73308, 153408, 66908, 102208
       EXI=3, …
       EXR=15, …（仅墙折行）
```
`TYPE` 5=墙 / 6=板【事实】；`SECTID` ⇒ 2.7【事实】；`HOLEID=-9999` = 无洞【推断-高】；
`NUB = len(NETID)`（335/335 精确）【事实】；`NETID` = 围成板/墙的**有序闭合环**（335/335 全闭合）【事实】；
墙的 `EXR.-64/-63` = 厚度(m) 与半厚（T600 ⇒ 0.6/0.3）【推断-高】。

### 2.11 `$RIGID`（刚性楼板组，6 条）
`ID/FLOORID/NUB` + `SLABID` 列表（每行 20 个、续行 11 空格）。`NUB = len(SLABID)`【事实】；
6 组引用 331 块板恰好一次；**层 3 有两组**（18800 与 22800 夹层）——按 `FLOORID` 归并会错【事实】。
`$STORY.ID`/`$RIGID.ID` 是不带类别码的小整数【事实】。

### 2.12 荷载组（`$DEADLOAD`/`$LIVELOAD` + 6 类子段）
分组头自身 0 条记录；其后子段归属该工况，**同一段名可出现两次**（恒/活各一次），必须按
(节名, 工况) 二元组索引【事实】。子段：`$DEFNODELOAD/$SETNODELOAD`（节点荷载，KIND=1）、
`$DEFLINELOAD/$SETLINELOAD`（线荷载，KIND=2；TYPE=1 集中 / 101 均布）、
`$DEFSLABLOAD/$SETSLABLOAD`（面荷载，KIND=3/UCS=3）。
`SET*LOAD.LOADID` 正号 ⇒ 同名 DEF 表；**负号 ⇒ 跨表引用 `$DEFLINELOAD`**（恒载 4 面墙如此）【事实】。
`DS + S = 构件全长` 在均布样本成立【事实】。
> **本包不做荷载转换**（R2 §9.3，见 §4）；以上词表仅供读侧解析与人工核对。

## 3. ID 编码与词表

### 3.1 全局 ID：`ID = N × 100 + CC`【事实】

`CC` = 两位类别码（10 材料、09 框架截面、07 节点、08 线段/构件、11 墙板截面、05 墙、06 板、
12/13/14 荷载）；样本 2,841 个对象的 `N` 恰填满 1..2841、无缺号、无跨类复用 ⇒ 这是导出器的
**一次性全局流水号**，**禁止**用 ID 数字反推结构关系。

> **本包写出的差异（如实申报）**：`pdt_write` 目前按**类别各自从 1 重启发号**（材料 1..3、
> 截面 1..32、节点 1..617、构件 1..1046），`N*100+CC` 全 ID 在文件内仍无冲突，但与 §j.3
> "N 全局连续"的冻结文字不符——复核发现（见 `docs/交付报告.md` R2 第 20 条），**尚未改**。
> 对现有插件按名/按 ID 读取的影响**未实机验证**。

## 4. 荷载：**不参与转换**（R2 明确要求）

* **读侧**（`pdt_read`）：荷载节**可选解析**，塞不进规范模型的语义进 `notes`——v1 已实现并保留，不动；
* **写侧**（`pdt_write`）：**只写段头，体内为空**——`$DEADLOAD`（6 个子段头）+ `$LIVELOAD`（4 个），
  与样本同构但**无任何荷载记录行**（`engine/pdt_write.py` 的 LOAD_SEGMENT_BLOCK）；
  保证现有 Add-in 解析不炸；报告 `assumptions` 写明
  `荷载不导出（R2 §9.3）：只写 $DEADLOAD/$LIVELOAD 及其子段头，体内为空（§j.6）`；
* **荷载数据库方向同样不做**：目录/规格宏只有截面，无荷载内容；
* 验收实测（检查 9）：生成 `.pdt` 的荷载段记录数 `{'$DEADLOAD': 0, '$DEFNODELOAD': 0, …, '$SETSLABLOAD': 0}` 全 0；
  独立复核（复核脚本 rev3）：全文件无 `LOADID=/FZ=/PX=/UCS=` 字段。

## 5. 写出契约要点（`engine/pdt_write.py`，契约 §j）

1. **文件级**：GBK 无 BOM + CRLF（写后回读校验无孤立 `\n`）；首行 `;File <note> saved <M/D/YYYY H:M:S>`；
   第 2 行空行；每段 = 段头 + 数据行 + 1 空行；`$END` 前 2 空行后 1 空行；行尾空白不写（比对一律 rstrip）。
2. **与 DLL 格式串的裁定**（§j.8）：段名与 KEY 名/顺序以 DLL 格式串为准（Add-in 按名解析的硬要求）；
   数值格式与空白布局以**样本**为准（样本是 Add-in 自己写、也读得回去的往返证据）。
   已知差异 4 处（`$STORY` 的 WID/LEN/HEI 两位小数、元素 `EXR=` 后无空格、`EXI` 布局、
   `$DEFMATERIAL` 的 e 小写）——**不得自行"统一"**。
   实测：从 `PDMSxCA_Addin121.dll` 字节里搜到全部 17 条格式串（缺 0）；生成的 `.pdt` 与模板逐行比对
   3,377 行全部相符（检查 9：def_frame 4×28 行、exr 520、node 520、net 811、setelement 811…不符 0）。
3. **合成规则**：节点由构件端点合成（每唯一坐标一个节点，`FLOORID` 按 Z 所属层）；
   `$NET.ID == $SETELEMENT.ID`；板洞（`is_hole=True`）与零厚"房间"**不写** `$SETSLAB`（HOLEID 语义未证 ⇒ 不猜），逐条进 `skipped`；
   材料用内置表（C30/Q235/Q345，取样本里被构件引用的那条），缺表兜底 `(262,3e4,0.2,1e-5,25)` 并记 warnings。
4. **占位与不丢构件**：截面不可回算（Kind=2、Kind=26 族码≠39、Kind=303 之外的族）⇒ 写占位块
   （5 行，数值全 0、`SHAPE=<kind>`），引用它的构件照写，`skipped` 记 `section-shapeval`。
   **`TYPE=3`（支撑）与占位块能否被现有 Add-in 接受：未在 PDMS 实机验证**（§12#15、复核 R2 第 27 条）。
5. **两种骨架**：`full`（13 段全写，几何段可为空）与 `sections-only`（只写 首行+`$VERSION`+
   `$DESIGNPARA`+`$DEFFRAMESECTION`+`$END`，供 `db2pdt`/`pdms2pdt` 截面导出）。
6. **偏心**：`.jwd` 源的 `start/end` 已含偏心 ⇒ `ECS*=0.000`（避免二次施加）；
   `.pdt` 源的 `Member.ecc` 保留原值 ⇒ 写回 `ECS*`（R3 修正后行为；实测 jwd 源读回 ecc 非零 0 个、
   pdt→pdt 产物 ECS1 含 225.000/250.000）。
7. **往返验收**（§j.10，检查 9 已执行）：`.jwd → canonical → .pdt' → read_pdt` 层标高/构件端点/
   包围盒等价、`validate()` 无 `E-` 项、段序与荷载空段逐字比对通过。

## 6. 异常清单（会绊倒重新实现的点）

1. **缩进即语法**：正则"以 `KEY=` 开头即新字段"会错（EXR 折行以裸值开头）；"行首无缩进才是新记录"也会错（所有数据行都有缩进）。
2. **孤立节点 2 个**（墙中线交点残留）⇒ 按 NET 端点集合过滤，不要按节点建点。
3. **`FLOORID` ≠ 几何层**（38 个节点不符）且 `$STORY` 只覆盖 11 个标高中的 5 个 ⇒ **必须按节点 Z 分组建标高**，否则丢 -5000 基础层与 22800 夹层。
4. **`EXR=26` 的孤例构件**（多 7 个属性、5 行 EXR）⇒ 不能假设"每条 `$SETELEMENT` 恰好 4 行/固定属性集"。
5. **材料重名** ⇒ 按 ID 取材料（§2.8）。
6. **`$SETSLABLOAD` 混装墙与板**且墙的 `LOADID` 带负号 ⇒ 只按数值查 `$DEFSLABLOAD` 会丢 4 面墙的恒载（本包不做荷载，读侧需知）。
7. **`DS/S` 单位是 m**，几何是 mm。
8. **`$RIGID` 6 组 > 5 层**。
9. **`$DESIGNPARA` 有 20 行全零**且无字段名 ⇒ 不要按"每行一个参数组"猜语义。
10. **数值文本**可能出现 ` 2 `、`2e+06`、`-0.000` ⇒ 先 strip 再 `float()`。

（完整 16 条见 `_recon/pdt_format.md` §9；本节摘录与转换直接相关的。）
